PROBLEM STATEMENT:
------------------
Changes to About Us and Sister Hotel in the admin panel (hoteladmin.html) 
saved correctly and showed in the backend, but did NOT display on the front 
end (index.html). The data was being saved to Firebase but couldn't be read.

ROOT CAUSE:
-----------
Missing Firebase security rules for the 'siteContent' path. Without read 
permission, the front end couldn't access the data even though it was saved.

THE FIX:
--------
Added 4 lines to database.rules.json to enable public read access and 
authenticated write access for the 'siteContent' path.

FILES MODIFIED:
---------------
1. database.rules.json (4 lines added)
   - Added "siteContent" security rules
   - ".read": true (public read for front end display)
   - ".write": "auth != null" (authenticated admin write)
